# Parcial-N-1-Programacion-3
Entrega de Proyecto para primer parcial

DESCRIPCIÓN

El presente proyecto consta de la implementación del frontend de una pagina para delivery de comidas. El sitio en cuestión cuenta con dos vistas iniciales (login y registro) para que el usuario se registre con su email, o de lo contrario efectue el inicio de sesion en caso de contar con una cuenta existente. La persistencia de los datos de usuario, como de las diferentes funcionalidades implementadas en el la home page, residen en localStorage con finalidad exlclusivamente académica. 
Una vez que el usuario realiza el login, la pagina de inicio cuenta con una barra de navegación, para realizar distintas acciones ( aquellas funcionales, siendo el carrito, inicio, y cerrado de sesion), 
seguido de un panel lateral en el sector izquierdo, que cuenta con diferentes categorías de productos. 
La sección principal de la home page, se divide entre un buscador, y un listado de productos para navegar las diferentes opciones de comida ofrecidas por el sitio.

Las funcionalidades necesarias desarrolladas para los elementos de la homepage son las siguientes:
- Listado dinámico de productos
- Filtrado por categorías
- Búsqueda por nombre
- Carrito de compras persistente (localStorage)
- Agregado de productos al carrito
- Visualización de productos en el carrito
- Cálculo de subtotal, envío y total
- Mensaje de carrito vacío

INSTRUCCIONES PARA CORRER EL PROYECTO

Requisitos previos: instalar node.js y pnpm
- Clonar repositorio: git clone https://github.com/IBuKi19/Parcial-N-1-Programacion-3.git
- Acceder al directorio via:  cd nombre-proyecto
- Instalar dependencias: pnpm install
- Ejecutar servidor: pnpm dev
